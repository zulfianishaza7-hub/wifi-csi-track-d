# Dataset

Project ini menggunakan dataset Widar 3.0 untuk eksperimen cross-environment WiFi CSI gesture recognition.

Struktur folder:

- `raw/` : data CSI mentah
- `processed/` : data yang sudah melalui preprocessing

Catatan:
File dataset tidak disimpan di GitHub karena ukurannya besar. Instruksi download dan preprocessing akan ditambahkan setelah pipeline data selesai dibuat.
