# Cross-Environment WiFi CSI Gesture Recognition

Project pengganti UTS mata kuliah Pembelajaran Mesin Lanjut.

## Track
Track D — Cross-Domain / Cross-Environment Sensing

## Tujuan
Membangun model Deep Learning berbasis WiFi Channel State Information (CSI) untuk mengenali gesture manusia dan menguji kemampuan generalisasi model pada lingkungan/ruangan yang berbeda.

## Dataset
Widar 3.0

## Model
- Baseline: 1D-CNN
- Proposed: Domain-Adversarial Neural Network (DANN)
